# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion focused on the project.
Harassment, discriminatory language, and personal attacks are not acceptable.

Report unacceptable behavior through the repository's private vulnerability
reporting channel or by contacting the maintainer directly. Reports are handled
confidentially.
