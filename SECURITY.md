# Security Policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ArnoNuyts/todotui/security/advisories/new).
Do not open a public issue for a security problem.

Include the affected version, your operating system and terminal, and steps to
reproduce. You can expect an initial response within a few days.
